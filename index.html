FacePass – Face Recognition

Browser-based facial recognition using client embeddings and Flask matching

Overview

FacePass is a hybrid facial recognition system where the browser handles detection and feature extraction, while the backend performs identity matching. The result is real-time recognition without needing GPU acceleration on the client.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

Pipeline

  • Browser: webcam capture → face detection → embedding extraction
  • Backend: embedding comparison → identity matching → response

Results

  • Live recognition on standard hardware
  • Stable under normal lighting
  • Front-facing images boost accuracy
