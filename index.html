FacePass

Face Recognition System using face-api.js & Flask

Overview

FacePass is a lightweight browser-based facial recognition system. The web browser performs live face detection using face-api.js while identity matching is handled by a Flask backend using stored embeddings.

Tech Stack

face-api.js
Flask
WebRTC
Python
HTML/CSS

Architecture

Client (Browser):

  • Accesses webcam via WebRTC
  • Detects face and computes embeddings
  • Sends embedding vectors to backend

Backend (Flask):

  • Receives embeddings
  • Compares with stored values
  • Returns predicted identity
