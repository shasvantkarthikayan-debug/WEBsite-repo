FacePass – Face Recognition
GitHub Repository →

Overview

FacePass performs real-time face recognition by extracting embeddings in the browser via face-api.js and matching identities through Flask on the backend.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

Pipeline

  • Client: webcam → detection → embeddings → send to backend
  • Backend: compare embeddings → match identity → respond
