FacePass – Face Recognition

Browser-based facial recognition using client embeddings + Flask matching

Overview

FacePass performs real-time face recognition by extracting embeddings in the browser using face-api.js and matching identities server-side using Flask.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

Pipeline

  • Client: webcam → detection → embedding extraction → send to backend
  • Backend: compare embeddings → match identity → return result

Results

  • Real-time recognition on standard hardware
  • Stable under normal lighting
  • Front-facing training images improve accuracy
