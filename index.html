FacePass – Face Recognition

Overview

FacePass performs real-time face recognition by extracting embeddings in the browser using face-api.js and matching identities server-side using Flask. This allows recognition without GPU on the client.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

Pipeline

  • Client: webcam → detection → embedding extraction → send to backend
  • Backend: compare embeddings → match identity → return result
