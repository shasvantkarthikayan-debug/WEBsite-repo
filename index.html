FacePass – Face Recognition

A browser-based facial recognition system using face-api.js & Flask

Overview

FacePass performs real-time facial recognition through a hybrid browser + backend pipeline. The browser uses face-api.js for face embedding extraction, while Flask handles recognition using stored embeddings.

Stack

face-api.js Flask WebRTC Python HTML/CSS

Demo

Click to watch demo on YouTube.

How It Works

Client (Browser):

  • Webcam accessed via WebRTC
  • face-api.js detects faces + computes 128-D embeddings
  • Embeddings sent to Flask backend

Backend (Flask):

  • Receives embeddings
  • Compares with stored embeddings (Euclidean distance)
  • Returns identity prediction

Architecture

  • Camera → Browser (face-api.js)
  • Embeddings → Flask Backend
  • Flask → Recognition Result → Client

Results

  • Real-time recognition pipeline
  • Stable performance under normal lighting
  • Accuracy depends on angle & clarity
  • Lightweight client-side compute
