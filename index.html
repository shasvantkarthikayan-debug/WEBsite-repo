FacePass

Face Recognition System using face-api.js & Flask

Overview

FacePass is a browser-based face recognition system. The client uses face-api.js for face detection & embedding, while a Flask backend performs identity matching using stored face embeddings.

How It Works

FacePass splits processing between the browser and backend for efficient real-time face recognition:

Client (Browser):

  • Accesses webcam using WebRTC
  • Detects face regions via face-api.js
  • Generates 128-D face embeddings
  • Sends embeddings to Flask backend

Backend (Flask):

  • Receives embedding vectors
  • Compares with stored embeddings
  • Computes Euclidean distance similarity
  • Returns predicted identity

Architecture

Pipeline:

  • Camera → Embedding (face-api.js)
  • Embedding → Recognition (Flask)
  • Flask → Recognition result returned to client

Results

  • Real-time detection & recognition
  • Stable performance under normal lighting
  • Accuracy depends on face angle & clarity
  • Low compute load on client-side
