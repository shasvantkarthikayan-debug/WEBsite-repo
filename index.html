Face Recognition Overview

FacePass runs directly in the browser using face-api.js for face detection & embedding, while Flask handles recognition on the backend.

Project Summary

The browser streams video and extracts face embeddings, which are sent to Flask. Flask compares them to stored embeddings and returns the predicted identity.

How It Works

1. Browser (Client)

  • Webcam via WebRTC
  • face-api.js processes frames
  • Embeddings extracted
  • Sent to Flask backend

2. Flask (Backend)

  • Receives embedding vectors
  • Compares to stored embeddings
  • Finds best match
  • Returns identity

Results

  • Real-time detection & recognition
  • Works best with front-facing images
  • Performs well in normal lighting
  • Accuracy drops in low light
