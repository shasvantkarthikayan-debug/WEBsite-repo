FacePass – Face Recognition

Browser-based facial recognition via face-api.js + Flask embeddings

Overview

FacePass performs real-time face recognition by extracting embeddings in the browser using face-api.js and matching identities server-side using Flask and stored embeddings.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

How It Works

Client (Browser):

  • Webcam via WebRTC
  • face-api.js detects + embeds face
  • Embeddings sent to backend

Backend (Flask):

  • Receives embeddings
  • Compares via Euclidean distance
  • Returns predicted identity

Results

  • Live recognition pipeline
  • Stable under normal lighting
  • Accuracy depends on clarity + angle
