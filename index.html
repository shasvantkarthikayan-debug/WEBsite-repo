FacePass – Face Recognition

Browser-based facial recognition via face-api.js + Flask backend embeddings

Overview

FacePass performs real-time face recognition by extracting embeddings in the browser using face-api.js and matching identities server-side using Flask and stored embeddings.

Tech Stack

face-api.js Flask WebRTC Python HTML/CSS

Demo

FacePass Demo

How It Works

Client (Browser):

  • Accesses webcam via WebRTC
  • Detects faces + extracts embeddings (128-D)
  • Sends embeddings to backend

Backend (Flask):

  • Receives embeddings
  • Computes Euclidean similarity
  • Returns predicted identity

Results

  • Real-time recognition pipeline
  • Stable under normal lighting
  • Accuracy depends on angle/clarity
